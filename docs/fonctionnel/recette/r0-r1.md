# Recette fonctionnelle — R0 « Socle » et R1 « Capturer »

Règles : `../regles-de-gestion.md`. Les valeurs par défaut non validées (Q-x) sont utilisées ici ; à ajuster si le client les change. Les liens aux critères d'acceptation des stories seront ajoutés par le PO (colonne « RG » = référence provisoire).

Jeu d'essai : monument A (n° 1, rayon 150 m), monument B (n° 2, rayon 150 m, à 600 km de A), monument C (n° 3, rayon 400 m). Explorateur de test « Marco », e-mail vérifié.
